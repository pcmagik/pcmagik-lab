# Ustalenia operatora

## D1 — zaakceptowana główna jest wzorcem podstron (2026-09-21)

Wygląd strony głównej jest zaakceptowany i pozostaje bez zmian. Naprawa danych nie upoważnia do zmiany jej układu, pasków, typografii, kolorów ani hero. Podstrony mają być spójne z główną: wspólne elementy korzystają z jej aktualnych stylów, zamiast utrzymywać osobną starszą wersję.

## D2 — repo pomiarowe tylko do odczytu (2026-09-21)

Operator zastrzegł wyłącznie odczyt `projekt-wiedza-z-yt`, ponieważ pracują tam inni agenci. Nie zmieniamy jego plików ani gałęzi. Wcześniejszy commit `133ad07` pozostaje niewłączoną propozycją; dalsza integracja eksportera należy do agentów tego repo.
