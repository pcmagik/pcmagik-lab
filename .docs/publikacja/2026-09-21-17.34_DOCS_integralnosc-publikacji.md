## Rzeczywisty automat

```text
rozglos.py --privacy public
  → izolowany preflight danych i HTML
  → usługa publikacji filmu
  → zapis youtube w odcinek.json
  → publikuj.py: pełny eksport + hak strony w katalogu staging
  → commit i push pcmagik-lab/main
  → GitHub Actions: testy → build → paczka publiczna → Pages
```

- Repo pomiarowe nie ma skonfigurowanego remote ani workflow. Push tego repo nie uruchamia publikacji. Pytanie o docelowy remote pozostaje bez odpowiedzi.
- Workflow strony uruchamia build przy pushu na `main` i `fix/**` oraz przy PR. Tylko `main` wdraża Pages, po udanym buildzie. Wersje akcji potwierdzono przez GitHub API i przypięto do SHA.
- Paczka Pages zawiera jawnie wybrane pliki produktu; nie obejmuje skryptów, dokumentacji roboczej, planów ani starych dowodów spoza eksportu. Zachowuje istniejące adresy promptów `tasks/*.txt`, README odcinków i mobilnych zrzutów.
- Eksporter odmawia automatycznej publikacji z brudnego repo strony lub gałęzi innej niż `main`; błędy pull nie są ignorowane. Nie commituje cudzej pracy przez `git add -A`.
- Błąd danych/preflight zatrzymuje wysyłkę filmu. Zapisany link YouTube pozwala wznowić samą stronę bez ponownego uploadu. `--force` pozostaje świadomą zgodą na nowy upload.
- Parser opcji publikacji obsługuje flagi w dowolnej kolejności; `--socials --privacy public` nie zmienia już publikacji na prywatną.
