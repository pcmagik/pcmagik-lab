02 / THE PROCESS

No black box.
Just the whole picture.

A benchmark is only useful if you can check it.
Here’s what goes into every experiment.

01

One variable at a time

Same prompt, same rig, one variable changed per test. The model is reloaded before every run. Repeated runs belong to each experiment; published examples are not a substitute for the full cohort.

{ }

Metrics from the run

Repeat the measurement before drawing a conclusion. One run does not establish a benefit. Effects counts code constructs; it does not judge appearance. Time and output tokens are not equivalent-work costs in this open-ended task.

⌘

Real hardware

Ryzen 5 PRO 3600, 32 GB DDR4 ECC and an RTX 3090 with 24 GB VRAM. Local models are served through LM Studio.
