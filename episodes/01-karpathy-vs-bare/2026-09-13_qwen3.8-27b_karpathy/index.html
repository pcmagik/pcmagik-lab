About

One measurement. One variable. One number.

Most AI benchmarks are marketing. PC Magik Lab is the opposite: every single episode is one measurement with exactly one changed variable — and the only conclusion we allow ourselves is one number on screen.

Same model, same card, same server. We flip one setting between two runs, record both results, and publish the difference. If the number is boring, the episode is short.

Every prompt, config and raw result file is committed to the repository, so anyone can re-run an episode on their own hardware and check the math.

01 · SETUP

One measurement

Each episode answers exactly one question with one repeatable, timed run on local hardware.

02 · METHOD

One changed variable

Between the two runs, exactly one thing changes — a rule, a flag, a setting. Nothing else moves.

03 · RESULT

One number on screen

The episode ends with a single honest number — tokens, seconds, percent — and the raw files to prove it.
