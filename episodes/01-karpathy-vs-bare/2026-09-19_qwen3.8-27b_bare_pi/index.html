03 · About

The method is the content

Every episode is one measurement with one changed variable and one number on screen.

01

One measurement

Each episode answers exactly one question with a real run on real silicon — the same prompt, the same model, the same card.

02

One changed variable

Everything else stays fixed. Only the thing under test moves between the two runs, so the difference is the signal, not the noise.

03

One number on screen

The verdict is a single number — seconds, tokens, GB — shown on screen and repeated until it sticks. If it doesn't fit on screen, it doesn't ship.

All prompts, scripts and raw result files for every episode are public. Re-run the measurements yourself — that's the whole point.
