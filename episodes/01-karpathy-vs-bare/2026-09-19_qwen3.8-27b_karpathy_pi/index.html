// 03 · Method

One measurement. One variable. One number.

PC Magik Lab is a measurement series about local AI. The method is deliberately narrow: every episode is one measurement with one changed variable and one number on screen — plus the raw files to verify it.

One measurement

One episode measures one thing: wall time, tokens, or throughput on a fixed task. No blended benchmarks, no vibes.

One changed variable

Between the A and B runs, exactly one thing changes. Same model, same prompt, same machine, same day.

One number on screen

Each episode lands on a single headline number. Prompts and raw outputs ship in the repo so you can re-run it yourself.
