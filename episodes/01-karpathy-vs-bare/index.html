Karpathy skills on Qwen3.8 27B: what you gain, what you lose | PC Magik Lab

Same model, same prompt, same rig. Five runs with nothing added, five with one Karpathy rules file, all at reasoning effort medium. Model reloaded before each run; every number comes from the run logs. "Effects" = occurrences of @keyframes, animation, transition, :hover, gradients, box-shadow, backdrop-filter, transform, event listeners, IntersectionObserver and inline SVG in the page code. All ten pages, prompts and logs are in the repository. Harness: Pi 0.85.1 (it sends reasoning effort medium by default). Sampling: LM Studio defaults, no fixed seed. Your numbers will differ from run to run; the pattern is what repeats.
