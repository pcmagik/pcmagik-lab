Methodology

How we measure things

The whole point is comparability. Every test in the series follows the same strict rules, so the only thing that ever changes is the thing we are testing.

01

Same prompt

Every model gets the exact same prompt. No cherry-picked questions, no tailored phrasing — one prompt, shared with you, used across the board.

02

Same rig

All runs happen on the very same machine — one workstation, one NVIDIA RTX 3090 24 GB. The hardware never changes between tests.

03

One variable at a time

Each test changes exactly one variable. That is what makes a result readable: you always know what moved and what stayed put.

04

Model reloaded before every run

The model is fully reloaded before each single run. No warm caches, no leftover state — every run starts from a cold, clean load.

05

Everything published

Every prompt and every result file is published to the open repository. Read the raw output yourself — no screenshots of what we like best.

06

Repeatable by you

Because the prompt, the rig and the method are all out in the open, anyone with a compatible GPU can re-run a test and compare notes.
