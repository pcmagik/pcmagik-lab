The method

How the series measures things

No vibes-based benchmarks. Every test follows the same rules, so comparisons across models are actually fair.

01

Same prompt

Every model in a test answers the exact same prompt. If the input changes, the comparison is over.

02

Same rig

One machine, one GPU: the same hardware is behind every single run in the series.

03

One variable changed per test

Each test changes exactly one thing — so you can attribute any difference in the output to that one change.

04

Model reloaded before every run

The model is reloaded before every run, so no run inherits state from the one before it.
