01 · Method

How the series measures things

Every comparison in the series follows the same disciplined routine, so the only thing moving between tests is the thing being tested.

01

Same prompt

The exact same prompt is used across the board, so every model is judged on identical input.

02

Same rig

Every run happens on the same machine — one fixed setup, so hardware is never the variable.

03

One variable per test

Each test changes exactly one variable. That keeps the outcome attributable, not muddled.

04

Model reloaded before every run

The model is reloaded before every single run, so no test inherits state from the one before it.

05

Everything published

Every prompt and every result file is published in the open — nothing stays behind the camera.

Repeatable by design. Because the prompt, the rig, and the procedure are fixed and every prompt and result file is published, anyone can reproduce a test from the repository.
