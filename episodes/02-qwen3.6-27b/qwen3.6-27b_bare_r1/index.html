How We Measure

Every test follows a strict methodology so results are reproducible and comparable.

Same Prompt

Every model is evaluated with the exact same prompt, ensuring a fair apples-to-apples comparison.

Same Rig

One dedicated hardware setup is used for all tests — no swapping, no cloud, no variables.

One Variable Changed

Only one variable is changed per test — the model — keeping everything else constant.

Fresh Reload

The model is fully reloaded before every single run to eliminate caching bias.

Everything Published

Every prompt and every result file is published openly in the project repository.
