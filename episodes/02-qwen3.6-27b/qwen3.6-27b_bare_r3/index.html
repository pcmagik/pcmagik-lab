How We Measure

Every test follows the same rigorous protocol so results are comparable and reproducible.

Same Prompt

Every model is evaluated against the exact same prompt inputs, ensuring a fair and consistent comparison across all tests.

Same Rig

All benchmarks run on a single, fixed hardware setup — one GPU, one system — so nothing changes except what we're testing.

One Variable at a Time

Only one parameter or model changes per test. Everything else stays locked so the result reflects that single difference.

Full Reload Between Runs

The model is fully reloaded from disk before every single run, eliminating any cached-state bias from previous tests.

Everything Published

Every prompt, configuration, and result file is published in the public repository so anyone can verify or reproduce the tests.

Transparent & Reproducible

The entire methodology is open. No hidden parameters, no cherry-picked results — just honest benchmarks you can trust.
