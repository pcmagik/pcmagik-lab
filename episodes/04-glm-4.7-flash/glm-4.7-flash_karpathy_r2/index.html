Methodology

Same Prompt

Every test uses identical prompts to ensure fair comparison between different models.

Same Rig

Consistent hardware setup across all tests to isolate model performance differences.

One Variable

Only one factor changes per test: the AI model being evaluated.

Model Reload

Each model is fully reloaded before every run to ensure fresh starts.

Publish Results

Every prompt and result file is published for transparency and reproducibility.
