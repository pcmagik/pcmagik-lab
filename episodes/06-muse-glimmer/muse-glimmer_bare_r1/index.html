How we measure

The series is built for comparability. Every test follows the same protocol so results can be trusted and reproduced.

🧪

Same prompt

Identical prompts are used across runs to eliminate input variance.

🖥️

Same rig

All measurements are performed on the same physical system.

1️⃣

One variable

Only one parameter is changed per test for clear cause and effect.

🔄

Model reloaded

Every run starts with a fresh model load to avoid state carryover.

📁

Published files

Every prompt and result file is published for transparency.

About

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The focus is on practical benchmarking, clear methodology, and reproducible results.

The channel publishes tests with the same prompt, same rig, one variable changed per test, model reloaded before every run, and every prompt and result file published.
