How we measure

Consistency first. Every test follows the same protocol so results are comparable.

1
Same prompt
Identical input across all runs to eliminate prompt variance.
2
Same rig
One hardware setup for the entire series.
3
One variable changed per test
Isolate the change to see its real impact.
4
Model reloaded before every run
Cold start each time for fair timing.
5
Every prompt and result file published
Full transparency. Check the repository for raw data.
