Methodology

How We Measure

Every test follows a strict, repeatable protocol so you can trust the results.

Same Prompt, Every Time

The identical prompt is used across all runs, ensuring a fair and apples-to-apples comparison between models and configurations.

Same Rig, One Variable

All tests are run on the same hardware. Only one variable is changed per test — the model or a single parameter — so the impact is clear.

Model Reloaded Before Every Run

Each model is freshly loaded before every single test to eliminate cache effects and guarantee consistent starting conditions.

Every Prompt & Result Published

All prompts and result files are open and accessible so anyone can verify, replicate, or extend the tests.

About

About This Series

PC Magik Lab is a YouTube series dedicated to testing and comparing local AI models on real, consumer-grade GPUs.

PC Magik Lab is a YouTube series that puts AI models through their paces on real, local GPUs — the kind you'd have in your own home lab.

Every episode follows a strict methodology: the same prompt, the same rig, one variable changed per test. Models are reloaded before every run, and every prompt and result file is published for full transparency.

The goal is simple: honest, reproducible benchmarks that anyone can verify and build on. No cloud instances, no lab-grade equipment — just consumer hardware and real results.
