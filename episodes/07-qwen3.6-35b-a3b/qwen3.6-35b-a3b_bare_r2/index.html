Methodology

How we measure

Every test is designed for clarity and reproducibility. Same prompt, same rig, one variable changed at a time.

Same Prompt

Every model is tested with the identical prompt, ensuring a fair and apples-to-apples comparison.

Same Rig

All tests run on the exact same hardware setup, eliminating hardware variance from the results.

One Variable at a Time

Each test changes exactly one variable, so you always know what caused the difference in results.

Reloaded Every Run

The model is reloaded before every single run, ensuring no state carries over between tests.

Publish Everything

Every prompt and every result file is published openly, so anyone can verify the results independently.

About

About the series

PC Magik Lab is a YouTube series dedicated to running AI models on real, local GPUs — no cloud, no emulators, no abstractions.

Every episode tests a model on real hardware, with full transparency: prompts, results, and methodology are all published openly.

The goal is simple — show what local AI actually looks like, measured honestly on real machines.
