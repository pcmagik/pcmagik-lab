Methodology

How we measure things

Every test in this series follows a strict, repeatable protocol — so results are comparable and trustworthy.

Same Prompt

The identical prompt is used across every run, ensuring a fair and apples-to-apples comparison between models.

Same Rig

All tests run on the exact same hardware configuration. No swapping machines, no variable environments.

One Variable at a Time

Each test changes exactly one variable — typically the model under test — so you always know what caused the difference.

Model Reloaded Every Run

The model is reloaded fresh before every single benchmark, eliminating cache and memory-leak artifacts.

Everything Published

Every prompt file and every result file is published to the public repository — fully transparent and reproducible.

About

What is PC Magik Lab?

A YouTube series dedicated to running local AI models on real, physical GPUs — no cloud, no emulators, no abstractions.

🎯 Mission

Demystify local AI inference by running real benchmarks on real hardware, with full transparency on every prompt and result.

🔬 Approach

Strict, controlled testing: same prompt, same rig, one variable changed per test, model reloaded before every run, every file published.

🌐 Community

Open-source everything. Prompts, results, and methodology are all available for anyone to review, reproduce, and extend.
