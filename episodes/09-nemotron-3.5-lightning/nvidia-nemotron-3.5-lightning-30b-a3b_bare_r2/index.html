About PC Magik Lab

PC Magik Lab is a YouTube series by Mateusz Piekut, a computer service and homelab operator from Poland. The series explores the practical reality of running AI models on local, real GPU hardware.

Unlike cloud-based services, every episode tests actual model performance on physical hardware that's owned and operated locally. Each test uses the same prompt, the same rig, and only one variable changed — ensuring clear, comparable results.

Before every run, the model is reloaded to start from a clean state. All prompts and result files are published openly, allowing anyone to verify the results or replicate the tests themselves.
