How the series measures things

1

Same Prompt

Every test uses the exact same prompt to ensure comparability across models and configurations.

2

Same Rig

All tests run on the same hardware configuration to isolate model performance variables.

3

One Variable Changed Per Test

Only one parameter is modified per run to clearly identify what affects results.

4

Model Reloaded Before Every Run

The model is fully reloaded before each test to ensure clean state and consistent results.

5

Every Prompt and Result Published

All prompts and result files are published openly for transparency and reproducibility.

About

PC Magik Lab is a YouTube series created by Mateusz Piekut, a computer service technician and homelab operator based in Poland. The series explores the practical side of running AI models on consumer-grade hardware.

Each episode focuses on testing one variable at a time, using the same prompt and the same rig to ensure fair comparisons. All prompts used and result files generated are published alongside every video for full transparency.
