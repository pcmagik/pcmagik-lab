The method

How the series measures things

Every test follows the same rules, so comparisons across models are fair and repeatable.

01

Same prompt

Every run of a given test is asked the exact same prompt — no variations that could skew the numbers.

02

Same rig

Every test runs on the one and only machine, so hardware is never a hidden variable.

03

One variable at a time

Each test changes exactly one thing, so you always know what moved the result.

04

Model reloaded every run

The model is reloaded before every single run, so nothing leaks between measurements.

05

Everything published

Every prompt and every result file is published, so anyone can check the work end to end.

About

Real hardware. Real local models.

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The focus is on honest, repeatable measurement — the same prompt, the same rig, one variable changed per test.

Everything tested comes from a single local machine, and all of the prompts and result files are published so the process can be checked by anyone. No cloud, no black boxes — just models running on hardware you can point at.
