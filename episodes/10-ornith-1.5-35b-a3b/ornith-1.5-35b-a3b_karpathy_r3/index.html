How it works

A method built for trustable numbers

Every test is designed so the only thing that changes between runs is the one variable being measured. Everything else stays locked.

01

Same prompt

Every model is asked the exact same question, so responses are compared apples to apples.

02

Same rig

All runs happen on one home-built rig, so hardware never skews the comparison.

03

One variable per test

A single factor changes between runs, so every result can be traced to a clear cause.

04

Model reloaded every run

The model is reloaded before each test, so nothing leaks between runs.

05

Everything published

Every prompt and every result file is published, so the work can be checked by anyone.

About the series

Honest benchmarks for local AI

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The goal is simple: cut through the marketing and show how models behave on a genuine home setup.

The whole approach rests on a strict method — same prompt, same rig, one variable changed per test — with every prompt and result file published for anyone to verify.
