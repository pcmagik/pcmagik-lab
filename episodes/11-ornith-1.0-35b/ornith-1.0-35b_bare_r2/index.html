Methodology

How the series measures things

Every test is repeatable. Every result is published.

Same prompt, every time

The exact same input is used across all runs for fair comparison — no variation in what's being tested.

One variable at a time

A single factor is changed per test, so you can isolate exactly what affects performance.

Fresh model load each run

The model is reloaded into memory before every single benchmark — no stale state, no cache bias.

Published results

Every prompt and every result file is published — complete transparency for the community.

About the series

What is PC Magik Lab?

A YouTube series dedicated to running large language models on local, physical GPUs. No cloud services, no API calls — just raw hardware pushing tokens one inference at a time. The goal: honest benchmarks, transparent methodology, and open results for the community.
