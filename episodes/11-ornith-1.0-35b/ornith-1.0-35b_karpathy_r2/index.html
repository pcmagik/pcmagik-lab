Methodology

How we measure things

Same prompt, every time

The exact same input is fed to each model. No variation, no ambiguity — results are directly comparable.

Same rig, every run

All tests happen on a single machine. Hardware differences never confound the results.

One variable changed

Each test isolates a single factor — model, quantization, context window — so cause and effect are clear.

Model reloaded before every run

Cold starts, not cached inference. Every measurement reflects real-world conditions.

Fully reproducible

Every prompt and every result file is published open-source. Run the test yourself.

About

What is PC Magik Lab?

PC Magik Lab is a YouTube series dedicated to running AI language models locally on real consumer GPUs. No cloud APIs, no synthetic benchmarks — just hardware, open-source models, and honest measurements.

The goal is simple: figure out what runs well at home, share the results openly, and build a reference anyone can verify for themselves. Every prompt used in an episode and every result file is published to the public repository alongside each video.
