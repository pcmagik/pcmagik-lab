How we measure

Consistency first. The series is built around controlled testing so results are comparable and reproducible.

📝Same prompt

Every test uses the identical prompt to eliminate input variance.

🖥️Same rig

All runs are performed on one dedicated test system for fair comparison.

1️⃣One variable changed

Only a single parameter is altered per test to isolate its impact.

🔄Model reloaded

The model is reloaded before every run to ensure a clean state.

📂Published data

Every prompt and result file is published for transparency and reuse.

About PC Magik Lab

PC Magik Lab is a YouTube series focused on practical, local AI. The goal is to show what real GPUs can do with local models, measured transparently and shared openly.
