# One rules file. Twelve models.

The same Karpathy rules file on 12 local models, 3 runs without it and 3 with it on each model (for Qwen3.8 27B: the lowest, middle and highest of 5), 72 runs in the comparison. Run against run (9 pairs per model), only on Qwen3.8 27B did the model without the rules produce more effects in all 9 pairs; on the other 11 models the pairs split both ways. This page publishes all 12 models, the Qwen3.8 27B runs included (the same 3 of 5 per variant as the film). Harness: pi 0.85.1. Sampling: LM Studio defaults, no fixed seed.
