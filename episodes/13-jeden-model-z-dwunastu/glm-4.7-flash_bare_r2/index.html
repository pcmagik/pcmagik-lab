How We Measure

Same Prompt

Every test uses identical prompts to ensure fair comparisons between different models.

Same Rig

The same hardware setup is used across all tests to eliminate hardware variability.

One Variable

Only one thing changes per test: the AI model being evaluated.

Model Reload

Each model is fully reloaded before every run to ensure fresh starts.

Full Transparency

Every prompt and result file is published for complete reproducibility.

About

PC Magik Lab is a YouTube series dedicated to testing and comparing AI models running entirely on local hardware. The goal is to show what's possible with modern GPUs and to help viewers understand the capabilities and limitations of different models.

Every test is designed to be reproducible, transparent, and fair. By keeping all variables constant except for the model being tested, we can make meaningful comparisons between different AI solutions.
