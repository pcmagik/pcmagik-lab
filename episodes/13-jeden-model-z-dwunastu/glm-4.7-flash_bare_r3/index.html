Methodology

Same Prompt

Every test uses identical prompts to ensure fair comparison between models.

Same Rig

All tests run on the same hardware configuration for consistent results.

One Variable

Only one variable changes per test: the AI model being evaluated.

Model Reload

The model is reloaded before every single run to ensure fresh starts.

Full Transparency

Every prompt and result file is published for complete reproducibility.
