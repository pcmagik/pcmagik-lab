Why this matters

Using a single, real GPU and a local server removes cloud variability. LM Studio provides a stable interface for loading models locally, while the RTX 3090 offers a known compute baseline for the series.

Test discipline

Same prompt. Same rig. One variable changed per test. Model reloaded before every run. All prompts and results published.

About PC Magik Lab

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The focus is on practical, reproducible testing with clear methodology and open data.

The series does not invent episodes, results or statistics. It documents the process, shares prompts and result files, and keeps the hardware constant for fair comparisons.
