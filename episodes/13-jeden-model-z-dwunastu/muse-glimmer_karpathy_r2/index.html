How we measure

Consistent, repeatable testing with one variable changed per test. Full data published.

Same prompt

Every run uses the identical prompt to ensure comparability across models and settings.

Same rig

All tests are performed on the same hardware to eliminate system differences.

One variable

Only one variable is changed per test, keeping the experiment clean and interpretable.

Model reloaded

The model is reloaded before every run to avoid state carry-over and ensure fair starts.

Published data

Every prompt and result file is published in the repository for independent verification.

Hardware

One rig

NVIDIA RTX 3090 24 GB

All tests in the series are run on this single GPU to keep comparisons fair and reproducible.

Model server

LM Studio

Models are served locally with LM Studio. No cloud services, no hidden optimizations.
