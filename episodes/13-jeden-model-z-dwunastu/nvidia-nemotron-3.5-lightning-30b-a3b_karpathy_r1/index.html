How We Measure

Same prompt, same rig. One variable changed per test.

Every episode follows the same rigorous protocol: the model is reloaded before every run, ensuring that the only difference between results is the single variable being tested. All prompts and result files are published alongside each video on YouTube and in the repository.

Same Prompt

Every test uses the exact same prompt to ensure consistency across all episodes.

Same Rig

The test bench stays identical throughout the series - only the model variable changes.

One Variable Changed

Per-test, only a single model parameter or configuration variable is altered.

Model Reloaded Before Every Run

The model is fully reloaded before each test run to eliminate state carryover.

Every Prompt and Result Published

All input prompts and output result files are made publicly available alongside each episode.
