Method

How the series measures things

Every test is built to be fair and reproducible. One variable at a time, on the same machine, with everything published.

01

Same prompt, same rig

Every model is run on the identical hardware and software setup, so differences come from the model — not the machine.

02

One variable per test

A single setting changes between runs. Everything else stays fixed, so each result points clearly at what caused it.

03

Model reloaded before every run

The model is loaded fresh for each test, removing carry-over effects and keeping the numbers honest.

04

Every prompt published

The exact prompts used are shared in the repository, so anyone can reproduce the same inputs.

05

Every result published

Raw output and result files are made available — no cherry-picked numbers, nothing hidden behind a video.

06

Real local models

This is about running AI on real, local GPUs — not cloud benchmarks. The numbers reflect what you could get at home.

About

A series for people who run their own models

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. No cloud, no abstractions — just a desktop rig and honest measurements.

The focus is reproducibility: the same prompt, the same machine, and one variable changed per test. Every prompt and every result file is published so anyone can verify the numbers themselves.

If you care about what your own hardware can actually do, this is the channel for you.
