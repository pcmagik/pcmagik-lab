How it's measured

One variable. Every time.

The whole series is built on a repeatable, transparent method so every test can actually be compared.

01

Same prompt, same rig

Every run happens on one machine and is driven by the identical prompt, so results come from the hardware, not from noise.

02

One variable per test

Each test changes exactly one thing. That's what makes it possible to say which setting actually moved the numbers.

03

Model reloaded before every run

The model is reloaded fresh each time, so nothing leaks between runs and no warm cache hides the real behaviour.

04

Every prompt published

The full set of prompts lives in the repository, so anyone can reproduce exactly what was asked.

05

Every result file published

The raw result files are shared too, so the numbers behind each test can be checked and re-run.

06

Facts only

The series reports what was actually measured on the rig — no invented results, no fabricated statistics.

About the series

Benchmarking AI the way it should be done.

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The focus is on honest, repeatable measurement — the same prompt, the same rig, one variable changed per test.

The goal isn't to chase the biggest numbers. It's to show what these models actually do when they run on a single consumer card in a home setup, with everything reloaded and every result published for others to check.
