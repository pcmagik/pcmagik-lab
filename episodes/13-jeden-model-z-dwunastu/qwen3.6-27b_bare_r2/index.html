Methodology

How We Measure Things

Every test follows a strict, repeatable process so results are fair, transparent, and reproducible.

Same Prompt

Every comparison uses identical prompts, ensuring a fair apples-to-apples evaluation across models.

Same Rig

All benchmarks run on a single, consistent hardware setup so the only thing that changes is the variable under test.

One Variable Changed

Only one parameter or model setting is altered per test, keeping results clean and interpretable.

Model Reloaded Every Run

The model is fully reloaded from disk before every single run to eliminate caching artifacts.

Everything Published

Every prompt and result file is published in the public repository for full transparency and reproducibility.
