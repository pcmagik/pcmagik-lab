How We Measure

Every benchmark follows a strict protocol so results are fair, transparent, and reproducible.

Same Prompt

Every model is tested with identical prompts so there's no ambiguity about what it was asked to do.

Same Rig

All tests run on a single, fixed hardware setup. No swapping parts between benchmarks.

One Variable Changed

Each test isolates a single variable — usually the model — so differences in results are meaningful.

Model Reloaded Every Run

The model is fully reloaded before every single run to eliminate caching or state carryover.

Everything Published

Every prompt and every result file is published openly so anyone can verify the findings.

About This Series

PC Magik Lab is a YouTube series dedicated to running AI models locally — no cloud, no shortcuts. Each video puts real language models through real prompts on real hardware, so you can see how they actually perform when deployed on your own machine.


All prompts, results, and test files are published openly in the companion repository so you can reproduce every benchmark yourself.
