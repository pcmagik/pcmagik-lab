Method

How the series measures things

The only way to compare models fairly is to keep everything constant. The series follows a strict testing discipline:

01

Same prompt

Every model is tested with the same prompt, so responses are compared apples to apples.

02

Same rig

Every run happens on the same physical machine, so hardware differences never skew a result.

03

One variable per test

Only one variable is changed at a time, so any difference in output can be attributed to it.

04

Model reloaded before every run

The model is reloaded before every run, so no warm cache or leftover state carries over.

05

Everything published

Every prompt and result file is published to the repository, so anyone can check the work.

06

Verifiable by anyone

With the same prompt, the same rig and the same rules, results can be reproduced and checked.

About

Who's behind the lab

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. The idea is simple: skip the cloud hype and show what models actually do on hardware you can touch.

Every test follows the same rules — same prompt, same rig, one variable changed per test, the model reloaded before every run — and every prompt and result file is published so the work can be checked and reproduced.

The series is run by PC Magik (Mateusz Piekut), a computer service and homelab operator from Poland.
