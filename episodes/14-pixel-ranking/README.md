# Only 1 of 12 local model files never dropped below 28/29

12 local model files (11 models, Muse Glimmer in two files: Meta and Unsloth) built the same pixel art editor 3 times each, no rules, on one local GPU. A script grades every editor with 29 checks from the prompt. Muse Glimmer from the Meta file scored 28 in every run and never 29. 6 files reached 28 or 29 at least once and also dropped lower, sometimes to an editor where nothing can be drawn (Gemma 4 26B A4B 16–28, Gemma 4 31B 26–29, Muse Glimmer 30B (Unsloth) 24–29, Qwen3.6 27B 9–29, Qwen3.6 35B A3B 19–29, Qwen3.8 27B 26–29). Ornith 1.0 35B and Ornith 1.5 35B A3B never reached 28 (best run 26). 3 files never scored above 20: GLM 4.7 Flash, Nemotron 3 Nano and Nemotron 3.5 Lightning; every other file scored 26 or more at least once. 3 runs per file give groups, not a ranking. Effort: medium was requested; LM Studio logged that it swapped it for on in 9 of 12 files. Task: Pixel_Art_Editor from Prompt Vault. Harness: Pi. LM Studio defaults, no fixed seed; the model was reloaded before every run. Full cohort measurements, representative pages and prompts are available on the episode page.
