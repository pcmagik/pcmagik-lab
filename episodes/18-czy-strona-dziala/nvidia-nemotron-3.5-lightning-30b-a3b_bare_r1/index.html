How We Measure

Same prompt, same rig. One variable changed per test. The model reloaded before every run. Every prompt and result file published.

Same Prompt, Same Rig

Every test uses identical input prompts on the same hardware configuration to ensure comparable results.

One Variable Changed

Only one parameter is modified per test run, isolating the impact of each change on model performance.

Model Reloaded Before Every Run

The model is fully reloaded before each test run to ensure a clean state and eliminate cached effects.

Every Prompt and Result Published

All input prompts and result files are made publicly available alongside each video.

About

PC Magik Lab is a YouTube series by PC Magik (Mateusz Piekut) dedicated to exploring what's possible when you run AI models locally on real GPU hardware.

The focus is on transparency, reproducibility, and showing the real capabilities of consumer-grade hardware running open-source models.
