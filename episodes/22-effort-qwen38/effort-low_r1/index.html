Methodology

How we measure

The series keeps conditions tight so the only thing that moves is the variable under test — and everything is published so the work can be checked.

01

Same prompt

The same prompt is used across tests, so models are compared on identical input.

02

Same rig

Tests run on one fixed rig, so the hardware never changes between runs.

03

One variable at a time

Each test changes one variable at a time, so the result is attributable to it.

04

Reloaded before every run

The model is reloaded before every run, so each run starts from a clean state rather than a warm cache carried over from the previous one.

05

Everything published

Every prompt and result file is published, so anyone can read the exact inputs and the raw outputs behind each test.

The setup

One rig, one server

No swapping parts between runs — just one machine and one model server doing all the work.

PC Magik Lab is a YouTube series about running AI models on real, local GPUs — measuring how they actually behave on hardware you can put your hand on.

It's made by PC Magik (Mateusz Piekut), a computer service and homelab operator from Poland. The approach is simple and deliberate: run a model on a real GPU, keep the conditions tight, and publish the prompts and result files so anyone can check the work for themselves.
