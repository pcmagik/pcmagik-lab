Method

How every test is measured

Comparison only means something when the setup stays fixed. The series keeps the rules the same and lets exactly one thing change.

01

Same prompt

Every test runs the same prompt, so the comparison stays fair.

02

Same rig

All runs happen on the same machine — the one rig in the lab.

03

One variable

One variable is changed per test. That is the only thing allowed to change.

04

Fresh load

The model is reloaded before every run, so no run inherits state from the last one.

05

Fully published

Every prompt and result file is published, so any test can be checked line by line.
