01 · Methodology

How the series measures things

Fair comparisons need discipline. Every test in the series follows the same strict rules, so the only thing ever changing is what we want to test.

RULE 01

Same prompt

Every test runs the same prompt. What changes between runs is the model — never the words.

RULE 02

Same rig

One machine, one GPU. Results are never compared across different hardware.

RULE 03

One variable per test

Each test changes exactly one variable. Everything else stays fixed, so the outcome is never ambiguous.

RULE 04

Model reloaded before every run

The model is reloaded before every run, so no run ever inherits the state of the one before it.

RULE 05

Everything published

Every prompt and every result file is published in the public repository. Nothing is hidden.

03 · About

Who is behind the series

PC Magik (Mateusz Piekut) is a computer service and homelab operator from Poland. PC Magik Lab is his YouTube series about running AI models on real, local GPUs.

The approach is deliberately boring: the same prompt, the same rig, one variable changed per test, the model reloaded before every run — and every prompt and result file published in the open. If a claim matters, the file to back it up is in the repository.
