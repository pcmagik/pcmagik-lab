Methodology

How the series measures things

Every test follows the same discipline, so comparisons are fair and reproducible.

01

Same prompt

The same prompt is used for every comparison, so the input side of the equation never changes.

02

Same rig

Every run happens on the same machine, so differences come from what is being tested — not from the hardware underneath.

03

One variable at a time

One variable is changed per test, so the effect of a single change can actually be attributed.

04

Model reloaded every run

The model is reloaded before every run, so each test starts from a clean state rather than carrying over leftovers.

05

Everything published

Every prompt and every result file is published to the open repository, so anyone can check, reuse, or reproduce the tests.
