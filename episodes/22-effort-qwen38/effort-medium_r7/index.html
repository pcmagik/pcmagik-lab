How we measure

Method first, opinions later.

Every test in the series follows the same strict protocol, so results can actually be compared — and reproduced.

01

Same prompt

Every model under test receives exactly the same prompt. No special treatment, no cherry-picked phrasing.

02

Same rig

One fixed machine with one GPU runs everything, so hardware is never an excuse and comparisons stay fair.

03

One variable at a time

Each test changes exactly one variable. That way, any difference in output can be traced to a single cause.

04

Model reloaded every run

The model is reloaded before every run, so warm caches and leftover state can't skew the numbers.

05

Everything published

Every prompt and every result file goes into the public repository — check the work yourself.

06

Built to be reproduced

Prompts, setup and results are all there in the open, so anyone can rerun a test and verify it.
