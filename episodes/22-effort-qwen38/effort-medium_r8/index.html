How it's measured

Fair tests, by design

Every comparison in the series follows the same rules. No cherry-picked runs, no hidden settings — just controlled conditions and files you can inspect.

01

Same prompt, every test

Every model is asked the exact same things. The prompt is a fixed, published file — the input never changes between runs.

02

Same rig, every test

One machine does all the work: a single NVIDIA RTX 3090 24 GB. The hardware is a constant, so differences you see come from the model — not the box.

03

One variable at a time

Each test changes exactly one thing — a model, a setting, a context length — while everything else stays put. That's what makes a result mean something.

04

Model reloaded before every run

Before each run, the model is unloaded and loaded fresh. No warm-cache luck, no leftover state — every run starts from a clean slate.

05

Everything published

Every prompt and every result file goes into the public repository. You can read exactly what was asked and exactly what came back.

06

Results you can check

Nothing is taken on faith. If a claim matters, the file that proves it is one click away in the lab's public repo.
