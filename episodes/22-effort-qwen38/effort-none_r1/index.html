The method

How the series measures things

Comparisons are only meaningful when the setup is controlled. Every test in the series follows the same rules.

01

Same prompt

Every model gets the exact same prompt. No paraphrasing, no lucky retries — the input is identical across the board.

02

Same rig

One machine, one GPU. The hardware never changes between tests, so the model — not the box — is what you're comparing.

03

One variable per test

Exactly one thing changes per test. Change a model? Everything else stays fixed. That's the whole discipline.

04

Model reloaded before every run

Before each run, the model is fully reloaded. No warm caches, no leftover state — every run starts from a clean slate.

05

Everything published

Every prompt and every result file is published to the repository, so you can check the work yourself.

Why it matters: with the prompt, the rig, the reload and the publishing all fixed, the only moving part left is the model itself — which is exactly what the series is about.

The rig

One rig. No surprises.

The whole series runs on a single, unchanging workstation with a local model server. If the hardware changed, the comparisons wouldn't mean anything — so it doesn't.

PC Magik Lab is run by PC Magik — Mateusz Piekut, a computer service and homelab operator from Poland.

The series exists because of a simple frustration: claims about how well AI models perform are usually made on hardware the audience can't check, with inputs nobody else can see. So the lab inverts that — every test runs on a real, local GPU, with the same prompt, the same rig, one variable changed per test, the model reloaded before every run, and every prompt and result file published for anyone to inspect.

If you want to see local AI models put through their paces on hardware that actually exists — and see the receipts — that's the whole point of the channel.
