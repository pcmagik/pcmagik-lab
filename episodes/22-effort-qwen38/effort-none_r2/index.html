How the series measures things

One variable at a time. Nothing hidden.

Every test in the series follows the same strict routine, so the only thing changing between runs is the thing being tested.

01

Same prompt

The very same prompt drives every run. No rewording, no cherry-picking phrasing.

02

Same rig

One machine, one GPU, one server. The setup never changes between tests.

03

One variable per test

Each test changes exactly one thing — and only that one thing.

04

Fresh reload every run

The model is reloaded before every run, so no state carries over.

05

Everything published

Every prompt and every result file is published in the public repository.

Reproducible by design. Because the prompt, the rig and the procedure are fixed, anyone can pull the repository and run the exact same test on their own hardware.
