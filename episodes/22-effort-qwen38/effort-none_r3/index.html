How we measure

One variable at a time, on the same rig

Every test in the series follows the same ground rules, so results are comparable across episodes and reproducible by you.

input

Same prompt, every time

The exact same prompt drives every run in a test, so you are comparing models and settings — not different inputs.

hardware

Same rig

One machine, one GPU, one stack. The hardware never changes behind the scenes — only what is being tested changes.

design

One variable changed per test

Each test isolates a single change — a model, a setting, a context length — so the effect is actually visible.

fairness

Model reloaded before every run

The model is reloaded before every run, so no run benefits from a warm cache left over from the one before it.

transparency

Everything published

Every prompt and result file goes into the open repository — check the numbers yourself instead of taking them on faith.

The full method is the same in every episode: fix the prompt and the rig, change exactly one thing, reload the model before the run, and publish the prompt and the result.

PC Magik — Mateusz Piekut — is a computer service and homelab operator from Poland. He keeps hardware running, tames it when it misbehaves, and builds the kind of local setup he would actually use every day.

PC Magik Lab turns that day-to-day work into a YouTube series: real local GPUs, real models, and a measurement method that keeps every test fair and reproducible.

If you run (or want to run) AI on your own hardware, this is the series that shows what actually happens on the metal — with every prompt and result file published in the open.
