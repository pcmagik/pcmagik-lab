The method

How the series measures things

Every test follows the same five rules. No cherry-picking, no mystery setups — just a repeatable way of comparing what models actually do on real hardware.

01PROMPT

Same prompt

Every test runs the same prompt. If the output changes, it's the model or the setting that did it — never the question.

02RIG

Same rig

One machine runs everything. The hardware never swaps between tests, so it's never the hidden variable.

03Δ ONE THING

One variable per test

Each test changes exactly one thing — a model, a setting, a parameter. One change at a time, one comparison at a time.

04FRESH STATE

Model reloaded before every run

The model is reloaded before every run, so no test inherits state from the one before it. Every result starts clean.

05PUBLISHED

Everything published

Every prompt and every result file goes into the public repository. Nothing stays behind a video — the full record is out there for you to read.

The hardware

One rig. That's it.

No fleet, no mystery box. The entire series runs on a single rig: an NVIDIA RTX 3090 with 24 GB of memory, with LM Studio serving as the model server.

When something changes between tests, it's the one variable of the test — never the hardware underneath it.

About

Who's behind the series

PC Magik Lab is a YouTube series about running AI models on real, local GPUs. It's made by PC Magik (Mateusz Piekut) — a computer service and homelab operator from Poland — testing models on the kind of hardware you can actually sit in front of.

The point isn't hype; it's measurement. Same prompt, same rig, one variable changed per test, the model reloaded before every run — and every prompt and result file published in the repository, so the work stands on its own record.
