pcmagik-lab — protocol
Method

How the series measures things

One protocol for every test. Same prompt, same rig — and the only thing that ever changes is the single variable under test.

01

Same prompt

Every test starts from the same prompt, so the model is always answering the exact same question.

02

Same rig

The same machine runs every test. The hardware never quietly changes behind the scenes.

03

One variable per test

Each test changes exactly one thing. One change at a time is what makes a comparison meaningful.

04

Model reloaded before every run

The model is reloaded fresh before every run, so each one starts from a clean state.

05

Everything published

Every prompt and every result file goes to the open repository — you can check the raw material yourself.

About

The person behind the rig

PC Magik (Mateusz Piekut) is a computer service and homelab operator from Poland. PC Magik Lab is that homelab pointed at local AI: models running on a real, local GPU, on a YouTube series.

The idea is simple to follow and hard to fake — the same prompt, the same rig, one variable changed per test, the model reloaded before every run, and every prompt and result file published so anyone can check the work for themselves.
