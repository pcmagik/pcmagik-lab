01 · Method

How the series measures things

The rules of the lab are simple, and they are the same for every test.

01

Same prompt

The prompt is constant across the series. Same input, every single test — nothing is swapped or “optimized away”.

02

Same rig

Every test runs on the one rig in the lab. Same machine, every time — no hardware changing behind the scenes.

03

One variable per test

Each test changes exactly one variable — and only that one. When something moves, you know precisely what it is.

04

Model reloaded before every run

The model is reloaded before every run, so each test starts from a clean state instead of inheriting whatever the previous test left behind.

05

Everything published

Every prompt and every result file is published in the repository. No screenshots of cherry-picked runs — the raw files are there to check.
