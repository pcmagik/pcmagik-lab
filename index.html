A benchmark is only useful if you can check it.
Here’s what goes into every experiment.

01

One variable at a time

Same prompt, same rig, one variable changed per test. The model is reloaded before every run. The series standard is n=3 per variant; Film 01 uses n=5.

{ }

Metrics from the run

Read ranges across repeated runs: in the separate Qwen3.8 repeatability study, time varied by up to 93% within one variant. Effects counts code constructs; it does not judge appearance. Time and output tokens are not equivalent-work costs in this open-ended task.

⌘

Real hardware

Ryzen 5 PRO 3600, 32 GB DDR4 ECC and an RTX 3090 with 24 GB VRAM. Local models are served through LM Studio.
